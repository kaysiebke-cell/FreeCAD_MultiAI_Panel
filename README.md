# FreeCAD MultiAI Panel

An accessible, AI-assisted Python editor for FreeCAD with freely arrangeable panels, syntax highlighting and support for many AI providers. Intended for professionals, beginners and people with disabilities — the AI is a tool to assist, not to replace the user.

Quick start

- Install required package: `pip install requests`
- Put the folder `FreeCAD_MultiAI_Panel` into your FreeCAD `Mod` directory
- Restart FreeCAD and open the “FreeCAD MultiAI Panel” workbench
- Configure an AI provider via the Welcome dialog (or skip and set up later)

Documentation

Full documentation and detailed guides live in the `docs/` folder (see the existing documentation files).

Notes

- API keys are stored unencrypted in FreeCAD settings — do not use production keys.
- Requires FreeCAD 0.21+ and Python 3.10+. See `docs/requirements.md` for details.
